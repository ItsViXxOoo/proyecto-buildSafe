BuildSafe - Documentación del Proyecto

1. Resumen Ejecutivo

BuildSafe es una aplicación web para construir PCs personalizadas con recomendaciones inteligentes de componentes.

AspectoDetalle
StackReact 19 + Vite + TypeScript + React Router v7
BackendSupabase (PostgreSQL + Auth + Storage + Realtime)
Estado actualMVP funcional con Builder Rápido implementado
Base de datos887 componentes cargados (scraping de solotodo.cl)
DespliegueVercel (proyecto-build-safe.vercel.app)

2. Arquitectura

Frontend

  • React 19 con TypeScript y Vite 8 como build tool
  • React Router v7 para navegación SPA
  • Supabase JS Client para conexión directa con backend
  • Context API para estado global (Auth + BuilderRápido)
  • Hooks personalizados para lógica de negocio (useComponents, useBuilds, useCompatibility)

Backend (Supabase)

  • PostgreSQL 15 con Row Level Security (RLS)
  • Auth con confirmación de email
  • Storage con 3 buckets: avatars, component-images, build-covers
  • Realtime habilitado para actualizaciones en vivo
  • Edge Functions listas para lógica serverless

Autenticación

  • Registro con validaciones (username, nombre, apellido, email, password)
  • Login con email/password + mensajes de error traducidos
  • Persistencia de sesión (localStorage)
  • Redirección post-login con useLocation
  • Toast de feedback (login/logout)

CRUD Builds

  • Crear build con título y descripción
  • Eliminar build
  • Marcar como pública/privada
  • Agregar componente a build
  • Eliminar componente de build
  • Chequear compatibilidad (checkOnly + check)
